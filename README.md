# Sirimon Hikers Website

A hiking club website built with React and Vite.

## Setup Instructions

1. **Install dependencies:**
```bash
   npm install
```

2. **Run locally:**
```bash
   npm run dev
```
   Open http://localhost:5173

3. **Build for production:**
```bash
   npm run build
```

## Deploy to Vercel

1. Push this code to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Click "New Project"
4. Import your GitHub repository
5. Vercel will auto-detect Vite settings
6. Click "Deploy"

## Enable Password Protection on Vercel

1. Go to your project on Vercel
2. Settings → Deployment Protection
3. Enable "Password Protection"
4. Set a password for members

## Features

- Edit upcoming hike details
- Manage full year calendar
- Custom "what to bring" items
- Export to PDF
- Download calendar events (.ics files)
- Member registration
